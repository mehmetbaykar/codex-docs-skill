# Glossary

Use this glossary as a quick reference for Codex terms across the app, CLI, IDE extension, cloud, SDK, and related integrations.

- [Action](https://learn.chatgpt.com/docs/agent-approvals-security): An operation performed by a person, ChatGPT, or Codex, such as editing a file, running a command, or using a connected service. (Applies to: Desktop app, Web, Mobile, CLI, IDE extension, Cloud)
- [Agent](https://learn.chatgpt.com/docs): The Codex agent that reasons over context, uses tools, and completes a task. (Applies to: Desktop app, CLI, IDE extension, Cloud)
- [AGENTS.md](https://learn.chatgpt.com/docs/agent-configuration/agents-md): Repository or user guidance file that gives Codex persistent instructions. (Applies to: Desktop app, CLI, IDE extension, Cloud)
- [Analytics dashboard](https://learn.chatgpt.com/docs/enterprise/workspace-analytics): Admin hub for ChatGPT workspace adoption and Codex-focused reporting. (Applies to: Enterprise)
- [API key sign-in](https://learn.chatgpt.com/docs/auth#sign-in-with-an-api-key): Authentication using an OpenAI API key. (Applies to: Desktop app, CLI, IDE extension)
- [Approval policy](https://learn.chatgpt.com/docs/agent-approvals-security#sandbox-and-approvals): Rules for when Codex must ask before taking an action. (Applies to: Desktop app, CLI, IDE extension)
- [Approval request](https://learn.chatgpt.com/docs/agent-approvals-security#automatic-approval-reviews): Codex asking to allow a restricted action. (Applies to: Desktop app, CLI, IDE extension)
- [Apps (configuration)](https://learn.chatgpt.com/docs/plugins): Codex configuration and app-server fields that store connector settings under the `apps` name. (Applies to: Desktop app, CLI, IDE extension)
- [Appshot](https://learn.chatgpt.com/docs/appshots): Snapshot of the frontmost app window sent to a ChatGPT or Codex chat. (Applies to: Desktop app)
- [Auth cache](https://learn.chatgpt.com/docs/auth#login-caching): Locally stored login credentials reused by Codex. (Applies to: Desktop app, CLI, IDE extension)
- [Automatic approval review](https://learn.chatgpt.com/docs/agent-approvals-security#automatic-approval-reviews): Model-based review of eligible approval requests before they proceed. (Applies to: Desktop app, CLI, IDE extension)
- [Scheduled task](https://learn.chatgpt.com/docs/automations): A prompt ChatGPT runs at a future time or on a recurring schedule, with its own settings and run history. (Applies to: Desktop app, Web)
- [Scheduled run](https://learn.chatgpt.com/docs/automations#managing-tasks): One execution of a scheduled task, including its status and any resulting findings. (Applies to: Desktop app, Web)
- [Computer Use in the browser](https://learn.chatgpt.com/docs/browser?surface=app#app-computer-use-in-the-browser): Capability that lets ChatGPT operate the built-in browser directly. (Applies to: Desktop app)
- [Chat](https://learn.chatgpt.com/docs/projects#start-a-chat): A saved space for exchanging messages with ChatGPT or Codex, including shared context, results, and actions. Quick chat starts a ChatGPT chat from Codex. (Applies to: Desktop app, Web, Mobile, CLI, IDE extension, Cloud)
- [ChatGPT sign-in](https://learn.chatgpt.com/docs/auth#sign-in-with-chatgpt): Authentication using a ChatGPT account and workspace permissions. (Applies to: Desktop app, CLI, IDE extension, Cloud)
- [Computer History](https://learn.chatgpt.com/docs/customization/computer-history): Opt-in macOS feature that builds memories and a timeline from interaction events across allowed apps and websites. (Applies to: Desktop app)
- [Codex Cloud](https://learn.chatgpt.com/docs/cloud): Coding tasks that run in the cloud with their own workspaces, repositories, and tools. (Applies to: Desktop app, IDE extension, Web)
- [Cloud environment](https://learn.chatgpt.com/docs/environments/cloud-environments): Reusable repositories, dependencies, tools, and access settings for tasks in Codex Cloud. (Applies to: Cloud)
- [Cloud chat](https://learn.chatgpt.com/docs/environments/cloud-environments#how-codex-cloud-tasks-run): A Codex chat that runs remotely in a cloud environment. (Applies to: Cloud)
- [Codex](https://learn.chatgpt.com/docs): OpenAI's coding agent for software development tasks. (Applies to: Desktop app, CLI, IDE extension, Web, Cloud, SDK)
- [ChatGPT desktop app](https://learn.chatgpt.com/docs/app): Desktop app with ChatGPT and Codex, including Chat and Work, projects, file previews, scheduled tasks, and developer tools. (Applies to: Desktop)
- [Codex app-server](https://learn.chatgpt.com/docs/app-server): Local JSON-RPC server for embedding Codex threads, turns, approvals, history, and streamed events in custom clients. (Applies to: Desktop app, IDE extension, SDK)
- [Codex CLI](https://learn.chatgpt.com/docs/cli): Terminal client for running Codex interactively or in scripts. (Applies to: Terminal)
- [codex exec](https://learn.chatgpt.com/docs/non-interactive-mode): CLI command for running Codex non-interactively from scripts or CI. (Applies to: CLI)
- [Codex IDE extension](https://learn.chatgpt.com/docs/ide): Editor integration for using Codex inside IDEs like VS Code, JetBrains IDEs, Cursor, and Windsurf. (Applies to: IDE)
- [Codex SDK](https://learn.chatgpt.com/docs/codex-sdk): Programmatic interface for building Codex-powered workflows or integrations. (Applies to: SDK)
- [Codex-managed worktree](https://learn.chatgpt.com/docs/environments/git-worktrees#codex-managed-worktrees): A temporary worktree Codex creates and manages for a chat. (Applies to: Desktop app)
- [Compaction](https://learn.chatgpt.com/docs/prompting#context): Summarizing older context so long-running work can continue. (Applies to: Desktop app, CLI, IDE extension, Cloud)
- [Compliance API](https://learn.chatgpt.com/docs/enterprise/compliance-api): API for exporting supported ChatGPT workspace records and audit metadata. (Applies to: Enterprise)
- [Computer Use](https://learn.chatgpt.com/docs/computer-use): Desktop capability that lets ChatGPT interact with other applications through the UI. (Applies to: Desktop app)
- [config.toml](https://learn.chatgpt.com/docs/config-file/config-reference#configtoml): Local Codex configuration files. (Applies to: Desktop app, CLI, IDE extension)
- [Connected host](https://learn.chatgpt.com/docs/remote-connections#what-comes-from-the-connected-host): Computer or development environment that provides files, tools, and shell access for ChatGPT or Codex chats opened through remote connections. (Applies to: Desktop app, Mobile)
- [Connector](https://learn.chatgpt.com/docs/plugins): A component of a plugin that connects ChatGPT or Codex to data and actions in an external service. (Applies to: Desktop app (ChatGPT Work, Codex), Web (ChatGPT Work))
- [Conversation](https://learn.chatgpt.com/docs/projects#start-a-chat): The ongoing exchange of messages and shared context between a person and ChatGPT or Codex within a chat. (Applies to: Desktop app, Web, Mobile, CLI, IDE extension, Cloud)
- [Context](https://learn.chatgpt.com/docs/prompting#context): Information Codex can use while working, such as files, prior messages, tool output, and instructions. (Applies to: Desktop app, CLI, IDE extension, Cloud, SDK)
- [Context window](https://learn.chatgpt.com/api/docs/guides/conversation-state#managing-the-context-window): The maximum amount of information the model can consider at once. (Applies to: Desktop app, CLI, IDE extension, Cloud, SDK)
- [Custom agent](https://learn.chatgpt.com/docs/agent-configuration/subagents#custom-agents): User-defined agent role with its own instructions and settings. (Applies to: Desktop app, CLI)
- [Deny-read rule](https://learn.chatgpt.com/docs/permissions#deny-reads-with-exact-paths-or-globs): Filesystem permission rule that prevents Codex from reading sensitive paths or glob matches. (Applies to: Desktop app, CLI, IDE extension, Enterprise)
- [Diff](https://learn.chatgpt.com/docs/code-review?surface=app#app-what-changes-it-shows): Set of Git file changes shown for inspection, comments, staging, or reverting. (Applies to: Desktop app, Git, Review)
- [Domain allowlist](https://learn.chatgpt.com/docs/environments/cloud-environments#connect-to-services): Set of domains allowed by a Codex Cloud environment’s network policy. (Applies to: Cloud)
- [Environment (local)](https://learn.chatgpt.com/docs/environments/local-environment): Desktop app configuration that tells Codex how to set up worktrees for a project. (Applies to: Desktop app, Worktree)
- [Environment variable](https://learn.chatgpt.com/docs/environments/cloud-environments#environment-variables-and-secrets): Runtime configuration value available during task execution. (Applies to: Cloud, CLI, IDE extension)
- [Ephemeral session](https://learn.chatgpt.com/docs/non-interactive-mode#basic-usage): Non-interactive run that skips saving session state after it completes. (Applies to: CLI)
- [Fast mode](https://learn.chatgpt.com/docs/agent-configuration/speed#fast-mode): Speed setting that makes supported models respond faster at a higher credit cost. (Applies to: CLI, IDE extension)
- [Filesystem permission](https://learn.chatgpt.com/docs/permissions#filesystem-permissions): Permission profile rule that grants or denies read and write access to paths. (Applies to: Desktop app, CLI, IDE extension)
- [Finding](https://learn.chatgpt.com/docs/automations#managing-tasks): A notable result or issue surfaced by a scheduled task. (Applies to: Desktop app)
- [Full access](https://learn.chatgpt.com/docs/sandboxing#configure-defaults): Mode where Codex runs without normal sandbox restrictions. (Applies to: Desktop app, CLI, IDE extension)
- [Git worktree](https://learn.chatgpt.com/docs/environments/git-worktrees#whats-a-worktree): A second checkout of the same repository for parallel branch work. (Applies to: Desktop app, Git)
- [Handoff](https://learn.chatgpt.com/docs/environments/git-worktrees#working-between-local-and-worktree): Moving a chat and its work between Local and Worktree. (Applies to: Desktop app)
- [Heartbeat](https://learn.chatgpt.com/docs/automations#schedule-a-task-inside-a-chat): A recurring scheduled task that returns ChatGPT to the same chat. (Applies to: Desktop app)
- [Hook](https://learn.chatgpt.com/docs/hooks): A lifecycle handler that runs when a Codex event matches, such as tool use, permission requests, or when a turn stops. (Applies to: Desktop app, CLI, IDE extension)
- [Hook event](https://learn.chatgpt.com/docs/hooks#config-shape): Lifecycle point where configured hook handlers can run. (Applies to: Desktop app, CLI, IDE extension)
- [Hunk](https://learn.chatgpt.com/docs/code-review?surface=app#app-staging-and-reverting-files): Contiguous section of a diff that can be staged, unstaged, or reverted independently. (Applies to: Desktop app, Git, Review)
- [Inline comment](https://learn.chatgpt.com/docs/code-review?surface=app#app-inline-comments-for-feedback): Line-specific feedback attached to a diff. (Applies to: Desktop app)
- [Live web search](https://learn.chatgpt.com/docs/config-file/config-basic#web-search-mode): Real-time web lookup for current information. (Applies to: Desktop app, CLI, IDE extension)
- [Local](https://learn.chatgpt.com/docs/environments/git-worktrees#working-between-local-and-worktree): Mode where Codex works on the user's computer. (Applies to: Desktop app, CLI, IDE extension)
- [Local chat](https://learn.chatgpt.com/docs/environments/modes): A ChatGPT or Codex chat that runs on the user's machine. (Applies to: Desktop app, CLI, IDE extension)
- [Managed configuration](https://learn.chatgpt.com/docs/enterprise/managed-configuration): Organization-controlled Codex defaults and restrictions. (Applies to: Enterprise)
- [MCP](https://learn.chatgpt.com/docs/extend/mcp): Model Context Protocol, a standard for connecting Codex to external tools and context. (Applies to: Desktop app, CLI, IDE extension)
- [MCP resource](https://learn.chatgpt.com/docs/extend/mcp#supported-mcp-features): Readable context exposed by an MCP server for Codex to inspect. (Applies to: Desktop app, CLI, IDE extension)
- [MCP server](https://learn.chatgpt.com/docs/extend/mcp#supported-mcp-features): External tool or context provider exposed through MCP. (Applies to: Desktop app, CLI, IDE extension)
- [MCP tool](https://learn.chatgpt.com/docs/extend/mcp#supported-mcp-features): Action exposed by an MCP server that Codex can call during a task. (Applies to: Desktop app, CLI, IDE extension)
- [MDM](https://learn.chatgpt.com/docs/enterprise/managed-configuration#macos-managed-preferences-mdm): Mobile device management tooling for distributing device profiles and managed Codex settings. (Applies to: Enterprise)
- [Memories](https://learn.chatgpt.com/docs/customization/memories): Locally stored context Codex can reuse across sessions. (Applies to: Desktop app, CLI, IDE extension)
- [Model](https://learn.chatgpt.com/docs/models): The AI model Codex uses for reasoning and tool work. (Applies to: Desktop app, CLI, IDE extension, Cloud, SDK)
- [Network access](https://learn.chatgpt.com/docs/agent-approvals-security#network-access): Permission for commands or environments to reach the internet. (Applies to: Desktop app, CLI, IDE extension, Cloud)
- [Network policy](https://learn.chatgpt.com/docs/agent-approvals-security#network-policy): Domain-based allow and deny rules that constrain sandboxed outbound network traffic. (Applies to: Desktop app, CLI, IDE extension)
- [Non-interactive mode](https://learn.chatgpt.com/docs/non-interactive-mode): CLI mode for running Codex from scripts or CI. (Applies to: CLI)
- [Output schema](https://learn.chatgpt.com/docs/non-interactive-mode#create-structured-outputs-with-a-schema): JSON Schema passed to `codex exec` to constrain the final response. (Applies to: CLI)
- [Permission profile](https://learn.chatgpt.com/docs/permissions#define-and-select-a-profile): Named least-privilege policy that combines filesystem and network rules for local command execution. (Applies to: Desktop app, CLI, IDE extension)
- [Plan](https://learn.chatgpt.com/docs/learn/best-practices#plan-first-for-difficult-tasks): Codex's proposed or tracked steps for completing a task. (Applies to: Desktop app, CLI, IDE extension, Cloud)
- [Plugin](https://learn.chatgpt.com/docs/plugins): An installable bundle of capabilities, such as skills, connectors, and tools, distributed through the universal directory shared by ChatGPT and Codex. (Applies to: Desktop app (ChatGPT Work, Codex), Web (ChatGPT Work), CLI)
- [Plugin manifest](https://developers.openai.com/plugins/build/plugins#plugin-structure): Plugin metadata file that identifies a plugin and points to bundled skills, connector mappings, MCP servers, hooks, and metadata. (Applies to: Plugin authoring)
- [Prefix rule](https://learn.chatgpt.com/docs/agent-configuration/rules#understand-the-rules-language): Command-rule pattern that allows, prompts for, or forbids matching command prefixes. (Applies to: Desktop app, CLI, IDE extension, Enterprise)
- [Profile](https://learn.chatgpt.com/docs/config-file/config-advanced#profiles): Named configuration preset for Codex. (Applies to: CLI, IDE extension)
- [Progressive disclosure](https://learn.chatgpt.com/docs/build-skills): Loading skill details only when needed to preserve context. (Applies to: Desktop app, Web (ChatGPT Work), CLI, IDE extension)
- [Project](https://learn.chatgpt.com/docs/projects): A group of related chats and shared sources, or a local folder used for file-based work. (Applies to: Desktop app)
- [Prompt](https://learn.chatgpt.com/docs/prompting): A question, instruction, or goal sent to ChatGPT or Codex. (Applies to: Desktop app, CLI, IDE extension, Cloud, SDK)
- [Pull request review](https://learn.chatgpt.com/docs/code-review?surface=app#app-pull-request-reviews): Codex review of changes or feedback on a pull request. (Applies to: Desktop app, CLI, GitHub)
- [RBAC](https://learn.chatgpt.com/docs/enterprise/roles-and-workspace-permissions): Role-based access control for workspace permissions. (Applies to: Enterprise)
- [Read-only mode](https://learn.chatgpt.com/docs/sandboxing): Mode where Codex can inspect but not modify without approval. (Applies to: Desktop app, CLI, IDE extension)
- [Reasoning effort](https://learn.chatgpt.com/docs/config-file/config-basic#reasoning-effort): Setting that controls how much reasoning budget a model uses. (Applies to: Desktop app, CLI, IDE extension, SDK)
- [Remote connection](https://learn.chatgpt.com/docs/remote-connections): Connection that lets you access ChatGPT or Codex chats on another device through a connected host. (Applies to: Desktop app, Mobile)
- [requirements.toml](https://learn.chatgpt.com/docs/config-file/config-reference#requirementstoml): Admin-enforced requirements file for managed Codex setups. (Applies to: Enterprise)
- [Review pane](https://learn.chatgpt.com/docs/code-review?surface=app): Desktop app view for inspecting diffs, comments, and Git changes. (Applies to: Desktop app)
- [Rules](https://learn.chatgpt.com/docs/agent-configuration/rules): Policies that allow, prompt for, or deny command prefixes or permission exceptions. (Applies to: Desktop app, CLI, IDE extension)
- [Sandbox](https://learn.chatgpt.com/docs/sandboxing): Enforced boundary limiting what Codex commands can access or modify. (Applies to: Desktop app, CLI, IDE extension)
- [Sandbox mode](https://learn.chatgpt.com/docs/config-file/config-basic#sandbox-level): Configuration that defines Codex's filesystem and network limits. (Applies to: Desktop app, CLI, IDE extension)
- [Sandbox preset](https://learn.chatgpt.com/docs/codex-sdk#sandbox-presets): SDK shorthand for common sandbox policies such as read-only, workspace-write, or full access. (Applies to: SDK)
- [Schedule](https://learn.chatgpt.com/docs/automations): The timing rule for a scheduled task. (Applies to: Desktop app)
- [Network secret](https://learn.chatgpt.com/docs/environments/cloud-environments#environment-variables-and-secrets): A credential for a specific HTTPS service. Programs receive a placeholder; the proxy substitutes the credential for allowed destinations during setup and tasks. (Applies to: Codex Cloud)
- [Setup script](https://learn.chatgpt.com/docs/environments/local-environment#setup-scripts): Script run before the agent starts to install dependencies or prepare tools. (Applies to: Desktop app worktrees)
- [Skill](https://learn.chatgpt.com/docs/build-skills): Reusable workflow package with instructions and optional scripts or references. (Applies to: Desktop app, Web (ChatGPT Work), CLI, IDE extension)
- [Skill invocation](https://learn.chatgpt.com/docs/build-skills#how-codex-uses-skills): Explicit or implicit activation of a skill. (Applies to: Desktop app, Web (ChatGPT Work), CLI, IDE extension)
- [Slash command](https://learn.chatgpt.com/docs/developer-commands?surface=cli): Command entered with a leading slash to control or inspect a Codex CLI session. (Applies to: CLI)
- [Standalone scheduled task](https://learn.chatgpt.com/docs/automations): Scheduled task whose runs each start a new chat and report findings in Triage. (Applies to: Desktop app, Web)
- [STDIO MCP server](https://learn.chatgpt.com/docs/extend/mcp#stdio-servers): MCP server launched as a local process by a configured command and arguments. (Applies to: CLI, IDE extension)
- [Streamable HTTP MCP server](https://learn.chatgpt.com/docs/extend/mcp#streamable-http-servers): MCP server reached over HTTP, optionally with bearer token or OAuth authentication. (Applies to: CLI, IDE extension)
- [Subagent](https://learn.chatgpt.com/docs/agent-configuration/subagents): Specialized child agent spawned to work on part of a task. (Applies to: Desktop app, CLI)
- [Subagent workflow](https://learn.chatgpt.com/docs/agent-configuration/subagents#core-terms): Workflow where Codex runs delegated agents in parallel and combines their results. (Applies to: Desktop app, CLI)
- [Standalone task](https://learn.chatgpt.com/docs/projects): A Codex task that isn't grouped within a project. (Applies to: Desktop app, CLI, IDE extension, Cloud)
- [Task](https://learn.chatgpt.com/docs/projects): A defined outcome ChatGPT or Codex works toward, such as fixing a bug, creating a document, or researching a topic. (Applies to: Desktop app, Web, Mobile, CLI, IDE extension, Cloud)
- [Thread](https://learn.chatgpt.com/docs/app-server#threads): A technical object in Codex app-server APIs that contains turns and stored conversation history. (Applies to: App-server, SDK)
- [Scheduled task in a chat](https://learn.chatgpt.com/docs/automations#schedule-a-task-inside-a-chat): A scheduled task that uses an existing chat's context and returns each run's results to that chat. (Applies to: Desktop app, Web)
- [Thread fork](https://learn.chatgpt.com/docs/app-server#start-or-resume-a-thread): New thread branched from the stored history of an existing thread. (Applies to: App-server, SDK)
- [Turn](https://learn.chatgpt.com/docs/app-server#core-primitives): One exchange in a chat, usually a user prompt plus the agent's response and actions. (Applies to: Desktop app, CLI, IDE extension, Cloud, SDK)
- [Web search cache](https://learn.chatgpt.com/docs/config-file/config-basic#web-search-mode): Pre-indexed search results Codex can use without live browsing. (Applies to: Desktop app, CLI, IDE extension)
- [ChatGPT Work](https://learn.chatgpt.com/docs/get-started-with-work): The agent in ChatGPT for research, analysis, and creating documents, presentations, spreadsheets, and other finished work. (Applies to: Desktop app, Web)
- [Worktree](https://learn.chatgpt.com/docs/environments/git-worktrees): Mode where Codex isolates changes in a separate Git worktree. (Applies to: Desktop app)
- [Writable roots](https://learn.chatgpt.com/docs/agent-approvals-security#protected-paths-in-writable-roots): Directories Codex is allowed to modify. (Applies to: Desktop app, CLI, IDE extension)
